# Manual Rollback Procedure: Migrations 0057 & 0058

This document details the exact, step-by-step manual rollback procedure for database migrations `0057_oauth_handle_new_user.sql` and `0058_harden_paid_content_for_inactive_profiles.sql`.

> [!IMPORTANT]
> The rollback scripts are located in `supabase/rollback/` rather than `supabase/migrations/` to guarantee that they are **never automatically executed** during automated migration runs or CI/CD pipelines.

---

## 1. When to Use This Rollback
Execute this procedure only if you observe unexpected production regressions immediately following the application of migrations `0057` and `0058`, such as:
- Failures during reader signup or profile provisioning in `auth.users`.
- Unexpected access denials for legitimate readers in `get_chapter_for_reader`.
- Entitlement evaluation anomalies in `has_novel_entitlement` or `get_my_library`.

---

## 2. Step-by-Step Manual Execution in Supabase SQL Editor

Open the **Supabase Dashboard** -> **SQL Editor** with an administrative connection (`postgres` / `service_role`). Execute each script in its own separate editor tab:

### Step 2.1 — Rollback Migration 0058 (Paid Content Access)
1. Open a new tab in the Supabase SQL Editor.
2. Paste the entire contents of [`supabase/rollback/0058_rollback_paid_content_inactive.sql`](file:///e:/git-workstation/urdu-fiction-marketplace/supabase/rollback/0058_rollback_paid_content_inactive.sql).
3. Click **Run**.
4. **Verification**: Confirm the output reports `Success. No rows returned`.
   This restores:
   - `public.has_novel_entitlement(uuid)` to baseline [`0006_security_and_financial_hardening.sql#L98-L111`](file:///e:/git-workstation/urdu-fiction-marketplace/supabase/migrations/0006_security_and_financial_hardening.sql#L98-L111).
   - `public.get_my_library()` to baseline [`0016_reader_and_admin_orders.sql#L494-L549`](file:///e:/git-workstation/urdu-fiction-marketplace/supabase/migrations/0016_reader_and_admin_orders.sql#L494-L549).
   - `public.get_chapter_for_reader(text, integer)` to baseline [`0052_harden_suspended_writer_and_novel_visibility.sql#L126-L324`](file:///e:/git-workstation/urdu-fiction-marketplace/supabase/migrations/0052_harden_suspended_writer_and_novel_visibility.sql#L126-L324).
   - Exact privileges: `has_novel_entitlement` is granted to `authenticated, anon`; `get_my_library` and `get_chapter_for_reader` are granted to `authenticated`.

### Step 2.2 — Rollback Migration 0057 (handle_new_user Trigger)

2. Paste the entire contents of [`supabase/rollback/0057_rollback_handle_new_user.sql`](file:///e:/git-workstation/urdu-fiction-marketplace/supabase/rollback/0057_rollback_handle_new_user.sql).

4. **Verification**: Confirm the output reports `Success. No rows returned`.
